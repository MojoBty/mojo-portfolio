Veeva Systems

Software Engineer Intern — Core Documents Team

June–September 2026 · Pleasanton, California

Overview

I worked on the Core Documents team on the Vault platform, contributing to document functionality and internal tools used by developers.

Contributions

  • Built a dedicated React page for Core Documents actions in the internal administration console.
  • Migrated more than 20 internal administration actions from JavaScript and REST to TypeScript and GraphQL.
  • Developed reusable queries to simplify recurring document investigations.
  • Moved the document reclassify action from the viewer panel to the main action list and implemented backend permission and validation checks.

Technical Challenge: Reclassify Permissions

The reclassify action needed to determine which document types a user could select. This involved traversing the document type hierarchy and checking access permissions.

I reduced unnecessary database calls, used cached document type information, and introduced a bulk permission-checking call. These changes reduced the action permission API latency from approximately 14 seconds to 11 seconds.

Lessons Learned

This experience taught me to consider how a feature fits into the broader application. Discussions with other teams revealed edge cases that affected the implementation, reinforcing the value of early alignment and allowing enough time for design and security considerations.

Technologies

Java, React, TypeScript, GraphQL, and REST APIs.
