Projects

I developed these projects to explore building applications from scratch that can solve a specific problem. Each has given me opportunities to work with different tools and widen my knowledge of software development.

Riffed

A music discussion platform where users can participate in album-specific threads and general conversations.

Technologies

  • Next.js and TypeScript
  • Supabase and PostgreSQL
  • Tailwind CSS
  • Deezer API

My Contributions

I developed two thread types, integrated Supabase Auth for user authentication, and wrote SQL aggregations to power a most discussed view.

I also built a responsive grid interface across album and discussion views and implemented a server-side proxy to retrieve album metadata from the Deezer API.

Technical Focus

This project connected user authentication, discussion data, and external album metadata within one application. SQL aggregations supported a view of which albums generated the most discussion.

Challenges and Lessons

One challenge was writing the SQL query for the most discussed view. I needed to aggregate discussion activity by album and order the results by discussion count. This helped me better understand how SQL aggregations can turn application data into useful features.

IoT Time-Series Analytics Platform

A platform that collects simulated sensor readings, archives historical data, and generates forecasts.

Technologies

  • Python and Flask
  • InfluxDB
  • OpenStack Swift and Parquet
  • Pandas and Prophet
  • Docker

My Contributions

I simulated three IoT sensors and ingested approximately 259,000 time-series records daily using Flask and InfluxDB. I built a Pandas workflow to compute hourly and daily aggregates across more than 1.8 million records weekly.

Data Processing Workflow

  1. Generate readings from three simulated sensors.
  2. Ingest readings through Flask and store them in InfluxDB.
  3. Compute hourly and daily aggregates using Pandas.
  4. Archive historical data as compressed Parquet files in Swift object storage.
  5. Generate 24-hour forecasts for sensor temperature and resource usage using Prophet.

Technical Focus

The platform combines time-series queries with object storage for compressed long-term retention. It also uses historical readings to produce forecasts.

Challenges and Lessons

The biggest challenge for this project was designing the data processing workflow. I had to organize the timestamps and aggregate the data into consistent intervals. This taught me the importance of data preparation for analysis.

Outfitary

A full-stack application that lets users generate clothing items and outfits with AI.

Technologies

  • Next.js and React
  • Tailwind CSS
  • Python and Flask
  • OpenAI DALL-E 3

My Contributions

I developed functionality for creating, viewing, updating, and deleting clothing and outfit entries. I also created a Flask API that uses DALL-E 3 to generate and store images in under 15 seconds.

Technical Focus

This project connects a web interface with a Flask backend and an external image-generation service to support AI-assisted clothing and outfit creation.

Challenges and Lessons

I had to find a way to get consistent results from image generation, despite the non-deterministic nature of the DALL-E 3 API. The images generated did not always match the same style or background as other images. This taught me the importance of using clear prompts and evaluating images to ensure the output meets expectations.
